# Raven RSI experiment site

A static site presenting Raven RSI, recursive self-improvement on one task: the nanochat
pre-training run, the dam-break CFD case, the FEA limit-load search and the low-cost-model
comparison.

- Chinese: https://livxue.github.io/raven-rsi/
- English: https://livxue.github.io/raven-rsi/en/

It is plain HTML, CSS and JavaScript with its charts, fonts and videos bundled, so it needs no
build step. Raven itself lives at https://github.com/EverMind-AI/Raven.
